# The game's known functions and data, by name, for mods (NPJB-40001).
#
# Yakumo reads this file at build time; mods look the names up at run time
# through the "yakumo.symbols" service, yakumo.symbol() in scripts, or any
# hook that takes a name in place of an address. A name stays when Yakumo
# learns more; new names are added, none is reused for something else.
#
# Columns: kind, name, address, overlay ("-" for the executable, otherwise
# the code overlay the address belongs to, without ".ovl"), check, and what
# it is. A function's check is the FNV-1a hash (32-bit) of its first 16 bytes
# as the game ships them: on an executable whose bytes differ, the name is
# not given out. Data has no check. "On a quest" addresses hold other things
# outside one; read them only while game_task is in overlay.task_slot.
#
# Register names follow the MIPS convention: arguments in a0..a3, the result
# in v0. Every entry was traced in this project; docs/DATA_BIN.md,
# docs/LAYERED_ARMOR.md, docs/EQUIPMENT_MODS.md and docs/DEBUG_MENU.md say how.
#
